## 升级与兼容

- 支持的 Python 范围收敛为 3.12/3.13；默认 Docker 使用固定 3.12 基础镜像。
- 新环境按[安装说明](reproducible-delivery.md)消费 `uv.lock`；`pip install .` 仍可用于普通
  包安装，但它没有相同的依赖锁定保证，不能据此复刻本轮验收身份。
- `make eval` 改为独立断网测试容器，固定 Mock，不再操作已经运行的 Compose 服务。
  `make verify` 使用临时专属项目；原 `smoke` 命令仍面向调用者指定的已有服务。
- 本轮没有应用表迁移；当前 schema 仍为 `20261023_0008`。已有部署按数据库升级说明
  备份、停止旧进程后切换代码/镜像；验证用私有卷不参与真实数据迁移。
- 已冻结语料、上游夹具与旧结果保持原字节/实验身份。新增工具和安装流程的验证不能
  当作旧模型实验在当前源码上重跑。

## 已知限制

- 当前面向可信单用户，尚无多人权限、GitHub App/Webhook 或管理 UI。
- Redis List 队列没有 ACK/自动崩溃重领；租约续期、Worker fencing 和恢复调度尚未实现。
- SSE 历史到实时订阅仍有事件空窗；产物自动保留/清理尚未实现。
- Docker socket 是受信任的管理边界；不是远程强隔离或对任意恶意仓库的完备证明。
- provider 缺少完整 usage 时不能给出准确金额；GPT 本地大小/时长限制不能限制服务端计费。
- 最近三组各 0/6，未证明质量提升；真实路径本轮只做配置/流程核对，没有追加付费调用。
